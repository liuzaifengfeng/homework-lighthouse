# 作业灯塔 · 0.5.0 测试版

为个人学习通账号汇总作业，在安卓通知栏显示紧急任务，并在同步确认已提交或截止后移除提醒。

测试服务已部署，签名测试 APK 已在 Android 15 模拟器验证。服务器 4 项测试、安卓 11 项通知场景通过。完整结果见 `evidence/验收记录.md`。

## 规则

先判断提交状态：待批阅或已完成不催促；未开始等待开放。未交且显示正的剩余时间加入待办；未交但不显示剩余时间按已截止处理。这个规则由用户明确选择。网络失败、解析异常或记录暂时缺失不能当作已提交或截止。

- `server/`：Python 同步模块、SQLite 存储和鉴权 API。

- `作业灯塔-0.5.0-test.apk`：签名 release 测试包，不含调试广播入口。

## 手动任务与关注方式

作业页右上角“＋”添加手动任务，截止时间可不设置；任务右上角“⋮”选择提上日程、忽略不管，手动任务还可以标记完成。重点任务优先排列并立即进入关注通知；已忽略任务不提醒，可在分类栏“已忽略”中恢复。分类栏可横向滑动。手动任务与关注选择保存在本机，不提供跨设备同步或云端备份。详见 `0.4.0-更新说明.md`。

## 新版使用引导

底部“作业 / 提醒 / 我的”切换完整页面，作业状态在作业页内部筛选。提醒页可单独调整提前时间和实时模式；“我的”集中管理连接、五套主题、通知与后台运行、隐私说明及关于应用。页面保留各自滚动位置和筛选状态。详细说明见 `0.3.0-更新说明.md`。

当前仍为个人测试版，沿用现有服务器地址与令牌，尚未接入手机号注册或多用户账号。覆盖安装新版保留配置。

通知头显示最近截止任务的系统倒计时，展开后前两项分别计时，包含秒数。小米焦点通知 / 超级岛扩展数据已试验接入，但尚无 App ID 和授权设备，未验证小米真机渲染。“我的 → 小米焦点通知”可查看状态。详见 `0.5.0-更新说明.md` 和 `evidence/0.5.0-验收.md`。

## 通知行为

- 普通模式使用系统后台任务获取云端快照，执行时间可能受省电影响。
- 用户可开启 2 小时实时模式，每 30 秒拉取云端快照；结束后退回普通模式。
- 云端正常情况下每 5 分钟同步学习通，不会因手机每次查询而重新登录或抓取。
- 紧急作业合并为一条通知；每次拉取更新内容，已有任务不会重复响铃。
- 展开通知优先显示最近的两项作业，更多项以数量提示，给查看、稍后提醒和同步按钮保留空间。
- 提交或截止后从紧急通知中移除；所有紧急项结束时取消任务通知。
- 实时模式有独立的静默服务通知，可随时停止；任务全部提交时此服务通知仍保留到实时模式结束。
- 有效真实作业和演示数据分别缓存，演示不会改动学习通。
- 测试包有仅供自动验证使用的 DebugReceiver；正式 release 构建不包含此入口。

## 验证边界

模拟器可验证 Android 15 上的界面、后台通知更新、撤回及错误恢复，不能证明小米澎湃 OS 3 真机的后台策略。真实学习通提交须由用户自行操作，模拟提交只改测试服务的演示快照。

## 继续开发

当前工作区保留了 JDK 21、Gradle 8.11.1、Android SDK 35 和官方模拟器，均放在 `work/tools`，没有替换系统 Java 8。

在项目目录运行 `./Build-Android.ps1` 可构建 debug 和 release 测试包；加 `-DebugOnly` 只构建用于自动测试的包。测试签名密钥保留在工作区私有目录，不包含在源码包中。

若需要恢复手动测试隧道，可在 Windows PowerShell 中保持下列连接运行，再给模拟器配置端口反向转发：

```powershell
ssh -N -i "$env:USERPROFILE\.ssh\codex_deploy" -L 127.0.0.1:18765:127.0.0.1:18765 deploy@43.143.37.144
```

模拟器使用已配置的访问令牌；应用没有内置账号密码。手机使用上文的 HTTPS 服务入口。


## Git 仓库与桌面开发

桌面目录为源码工作副本，分支 `main`。安装包和历史验收截图仍保留在原工作区，不纳入 Git。私人连接参数、数据目录、密钥、缓存和本机路径配置不纳入 Git。

本机运行 `./Build-Android.ps1` 可继续使用原工作区工具链和原测试签名，覆盖安装保持一致。该脚本读取未提交的 `.local/workspace-path.txt`；其他电脑请执行 `./Build-Android.ps1 -WorkspacePath 你的工作区`，工作区需包含 `work/tools` 下的 JDK、Android SDK、Gradle 和 `work/private/android-test.jks`。直接使用 Gradle 时，可通过 `LIGHTHOUSE_SIGNING_KEY` 环境变量指定测试签名文件。
